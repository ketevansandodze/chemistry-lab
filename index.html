⚡ ქიმიის ინტერაქტიული გაკვეთილი

ჟანგვა-აღდგენითი რეაქციები

შეისწავლეთ ელექტრონების გადაცემის მექანიზმი, ივარჯიშეთ ჟანგვის რიცხვების გამოთვლაში და შეამოწმეთ ცოდნა ინტერაქტიულ ტესტში.

ელექტრონების გადაცემის ვიზუალიზაცია

დააკვირდით, როგორ კარგავს ელექტრონებს აღმდგენი (A) და იძენს მჟანგავი (B).

აირჩიეთ რეაქცია ზემოთ მოცემული ღილაკებიდან!

ჟანგვა (ელექტრონის გაცემა)

პროცესი, რომლის დროსაც ატომი ან იონი კარგავს ელექტრონებს. ნივთიერებას, რომელიც კარგავს ელექტრონებს, აღმდგენი ეწოდება, ხოლო თვითონ პროცესში ის იჟანგება (მისი ჟანგვის რიცხვი იზრდება).

აღდგენა (ელექტრონის მიერთება)

პროცესი, რომლის დროსაც ატომი ან იონი იძენს ელექტრონებს. ნივთიერებას, რომელიც იერთებს ელექტრონებს, მჟანგავი ეწოდება, ხოლო თვითონ პროცესში ის აღდგება (მისი ჟანგვის რიცხვი მცირდება).

ჟანგვის რიცხვის განსაზღვრის ძირითადი წესები

გაიხსენეთ სახელმძღვანელოდან მოცემული 10 ძირითადი წესი:

1

მარტივ ნივთიერებებში ატომების ჟანგვის რიცხვი ნულის ტოლია: Mg, O₂, N₂, Ar (ტოლია 0).

2

მარტივ (ერთატომიან) იონებში ჟანგვის რიცხვი იგივეა, რაც იონის მუხტი: Mg²⁺ (+2), O²⁻ (-2), N³⁻ (-3).

3

მოლეკულაში შემავალი ელემენტების ჟანგვის რიცხვების ალგებრული ჯამი ნულის ტოლია. (მაგ: H₂SO₄).

4

ფთორის, როგორც ყველაზე ელექტროუარყოფითი ელემენტის, ჟანგვის რიცხვი ყოველთვის -1-ის ტოლია (NaF, CaF₂).

5

წყალბადის ჟანგვის რიცხვი არამეტალებთან არის +1, ხოლო ლითონთა ჰიდრიდებში -1 (HCl, NaH).

6

ჟანგბადის ჟანგვის რიცხვი ძირითადად არის -2. გამონაკლისებია: პეროქსიდები (-1) და OF₂ (+2).

7

I და II ჯგუფის ლითონებისა და ალუმინის ჟანგვის რიცხვი დადებითია და რიცხობრივად უდრის ვალენტურ ელექტრონთა რაოდენობას (K₂S, MgÓ, AlCl₃).

8-10

გარდამავალ ლითონებსა და არამეტალებს სხვადასხვა ნაერთში შესაძლოა ჰქონდეთ ცვალებადი ჟანგვის რიცხვი. რთულ იონში ჯამი უდრის იონის მუხტს (SO₄²⁻ ჯამი = -2).

თეორიული მასალა (სახელმძღვანელოდან)

თავი 2. ელექტროქიმია, ჟანგვა-აღდგენის რეაქციები (გვ. 71-74)

ჟანგვის პროცესები ყოველდღიურობაში

ყოველდღიურ ცხოვრებაში ხშირად ვხვდებით ჟანგვის მაგალითებს. ალბათ, შეგინიშნავთ დაჟანგული ლურსმანი, გამავალშებული ვერცხლის ნაკეთობა, ან გაჭრილი ვაშლის ზედაპირზე წარმოქმნილი მუქი შეფერილობა — ეს ყველაფერი ჟანგვის პროცესს უკავშირდება.

ადრე ჟანგვას მიიჩნევდნენ, როგორც ჟანგბადის მიერთებას (ან წყალბადის დაკარგვას), ხოლო საპირისპირო პროცესს — ჟანგბადის დაკარგვას (ან წყალბადის მიერთებას) აღდგენას უწოდებდნენ. შესაბამისად, რეაქციებში:

C + O₂ → CO₂
2Ca + O₂ → 2CaO

ნახშირბადი და კალციუმი იჟანგება. თუმცა მოგვიანებით აღმოაჩინეს, რომ ჟანგბადი ყოველთვის არ მონაწილეობს ჟანგვის პროცესში, ამიტომ ძველი განმარტება შეიცვალა:

თანამედროვე განსაზღვრებით: ჟანგვა არის ელექტრონების გაცემის პროცესი, ხოლო აღდგენა — ელექტრონების მიერთების პროცესი.

ვალენტობა და ჟანგვის რიცხვი

ვალენტობა და ჟანგვის რიცხვი ერთი და იგივე არ არის. ზოგჯერ მათი რიცხვითი მნიშვნელობები არ ემთხვევა ერთმანეთს. მაგალითად, წყალბადის პეროქსიდში (H₂O₂) ჟანგბადის ვალენტობაა 2, ხოლო ჟანგვის რიცხვი — -1.

• მაგალითად, Na₂SO₄-ში გოგირდის ჟანგვის რიცხვის გამოსათვლელად ვადგენთ განტოლებას: 2·(+1) + x + 4·(-2) = 0 ⇒ 2 + x - 8 = 0, საიდანაც x = +6.

• KMnO₄-ში მანგანუმის ჟანგვის რიცხვია: 1 + x - 8 = 0 ⇒ x = +7.

• KClO₃-ში Cl-ის ჟანგვის რიცხვია: 1 + x - 6 = 0 ⇒ x = +5.

კითხვები და დავალებები (გვ. 74)
