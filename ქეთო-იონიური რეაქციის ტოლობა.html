იონური მიმოცვლის რეაქციები

ქიმია • ინტერაქტიული გაკვეთილი

ცენტრიდანული სწავლება
ძირითადი კანონზომიერება

იონური მიმოცვლის რეაქციები და მათი ბოლომდე წასვლის პირობები

ელექტროლიტების წყალხსნარებში მიმდინარე რეაქციებს, რომელთა დროსაც რეაგენტები ნაწილდებიან იონებად და ცვლიან შემადგენელ ნაწილებს, იონური მიმოცვლის რეაქციები ეწოდება.

ნალექის გამოყოფა

იონები უერთდებიან ერთმანეთს და ქმნიან წყალში უხსნად ნაერთს (↓).

წყლის წარმოქმნა

მჟავისა და ფუძის ნეტრალიზაციისას წარმოიქმნება მცირედ დისოცირებადი მოლეკულა — წყალი (H₂O).

აირის გამოყოფა

რეაქციის შედეგად გამოიყოფა აირი (↑), რომელიც ტოვებს სარეაქციო არის.

მოკლე იონური ტოლობის შედგენის წესი

  1. დაწერეთ მოლური (მოლეკულური) რეაქციის ტოლობა და გაათანაბრეთ კოეფიციენტები.
  2. ხსნადობის ცხრილის გამოყენებით განსაზღვრეთ რომელი ნივთიერებაა ხსნადი (იშლება იონებად) და რომელი — უხსნადი, აირადი ან სუსტი ელექტროლიტი (რჩება მოლეკულის სახით).
  3. ჩაწერეთ სრული იონური ტოლობა (ყოველი ხსნადი ელექტროლიტი დაშალეთ კატიონებად და ანიონებად).
  4. შეჭერით (გამორიცხეთ) ორივე მხარეს არსებული იდენტური იონები და მიიღეთ მოკლე იონური ტოლობა.

კლასიკური მაგალითი: ნეტრალიზაცია

განვიხილოთ ნატრიუმის ჰიდროქსიდისა და მარილმჟავას ურთიერთქმედება:

მოლეკულური: NaOH + HCl → NaCl + H₂O
სრული იონური: Na⁺ + OH⁻ + H⁺ + Cl⁻ → Na⁺ + Cl⁻ + H₂O
მოკლე იონური: H⁺ + OH⁻ → H₂O

ეს მოკლე იონური ტოლობა ადასტურებს, რომ ნებისმიერი ძლიერი ტუტისა და ძლიერი მჟავის ნეტრალიზაციის საფუძველი არის წყალბად-იონისა და ჰიდროქსიდ-იონის შერწყმა წყლის მოლეკულად.

ვირტუალური ლაბორატორია

იონური მიმოცვლის რეაქციების სიმულატორი

აირჩიეთ რეაგენტები, შეურიეთ ერთმანეთს და დააკვირდით მოლეკულურ, სრულ იონურ და მოკლე იონურ ტოლობებს.

ნეტრალიზაციის რეაქცია

ნატრიუმის ჰიდროქსიდისა და მარილმჟავას ურთიერთქმედება.

1. მოლეკულური ტოლობა
NaOH + HCl → NaCl + H₂O
2. სრული იონური ტოლობა
Na⁺ + OH⁻ + H⁺ + Cl⁻ → Na⁺ + Cl⁻ + H₂O
3. მოკლე იონური ტოლობა
H⁺ + OH⁻ → H₂O
სახელმძღვანელოს დანართი

ნივთიერებათა ხსნადობა წყალში

მოკლე საცნობარო ცხრილი მჟავების, ფუძეებისა და მარილების ხსნადობის დასადგენად.

ინტერაქტიული ტესტი

1. რომელი პირობა უზრუნველყოფს იონური მიმოცვლის რეაქციის ბოლომდე წასვლას?

პასუხი: რეაქცია ბოლომდე მიდის, თუ რეაქციის შედეგად წარმოიქმნება ნალექი (↓), აირი (↑) ან სუსტი ელექტროლიტი (მაგ. წყალი H₂O).

2. შედგენილია ბარიუმის ქლორიდისა და გოგირდმჟავას რეაქციის სრული იონური ტოლობა. რა იონი გამოისახება ნალექის სახით?

პასუხი: წარმოიქმნება ბარიუმის სულფატის თეთრი ნალექი:
Ba²⁺ + SO₄²⁻ → BaSO₄↓

3. შეესაბამება თუ არა მოკლე იონური ტოლობა H⁺ + OH⁻ → H₂O ნებისმიერი ძლიერი ტუტისა და ძლიერი მჟავის ურთიერთქმედებას?

პასუხი: დიახ, სრულად შეესაბამება. ყველა ძლიერი ტუტე და ძლიერი მჟავა წყალხსნარში სრულად იშლება იონებად და პროცესის არსი არის წყალბად-იონისა და ჰიდროქსიდ-იონის შერწყმა.
