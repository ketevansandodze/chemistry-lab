ელექტროლიტური დისოციაცია და ხსნარები

გაკვეთილი 1.10
თემა 1: ელექტროლიტური დისოციაცია და ხსნარები

მჟავებისა და ფუძეების სიძლიერე

მჟავები კლასიფიცირდება, როგორც ძლიერი და სუსტი მჟავები. მჟავების სიძლიერე განისაზღვრება წყალხსნარში წარმოქმნილი წყალბად-იონების რაოდენობის მიხედვით. როგორც უკვე აღვნიშნეთ, ნივთიერება, რომელიც სრულად დისოცირდება იონებად, ძლიერი ელექტროლიტია. შესაბამისად, ძლიერი მჟავა სრულად დისოცირდება წყალბად-იონისა და შესაბამისი ანიონის წარმოქმნით, ხოლო სუსტი მჟავა - ნაწილობრივ.

1

ძლიერი მჟავები

მარილმჟავა ძლიერი მჟავაა, ამიტომ მისი დისოციაციის პროცესი გამოისახება მხოლოდ ერთი ისრით:
HCl → H⁺ + Cl⁻

2

სუსტი მჟავები

ძმარმჟავა კი სუსტი მჟავაა და მხოლოდ მისი მცირე ნაწილი დისოცირდება, დანარჩენი რჩება მოლეკულის სახით. პროცესი შექცევადია:
CH₃COOH ⇌ CH₃COO⁻ + H⁺

დისოციაციის მუდმივა (Ka)

მჟავას სიძლიერის უფრო ზუსტად დასახასიათებლად გამოიყენება დისოციაციის მუდმივა, რომელიც წონასწორობის მუდმივას წარმოადგენს და ახასიათებს სუსტ ელექტროლიტებს (Ka).

ფორმულა:
Ka = ([CH₃COO⁻] · [H⁺]) / [CH₃COOH]

კვადრატულ ფრჩხილებში მოცემულია თითოეული ნაწილაკის მოლური კონცენტრაცია წონასწორობის მომენტში.

წყალხსნარები და ჰიდროქსონიუმი

თუ HA არის ძლიერი მჟავა, ის სრულად არის დისოცირებული და წყალხსნარში წარმოდგენილია მხოლოდ H⁺ (H₃O⁺) და A⁻ ის სახით.

HA(წყ) + H₂O(თხ) → H₃O⁺(წყ) + A⁻(წყ) (~100% დისოცირებული)
HA(წყ) + H₂O(თხ) ⇌ H₃O⁺(წყ) + A⁻(წყ) (მცირე % დისოცირებული)

ტუტეების (ფუძეების) სიძლიერე

ტუტეების სიძლიერე განისაზღვრება წყალხსნარში წარმოქმნილი ჰიდროქსიდ-იონების (OH⁻) რაოდენობით. ძლიერი ფუძე (ტუტე) წყალხსნარში სრულად დისოცირდება მეტალის კატიონისა და ჰიდროქსიდ-იონების წარმოქმნით.

KOH(მჟ) --H₂O--> K⁺(წყ) + OH⁻(წყ)

ძლიერი ტუტეები გამოიყენება ცხიმოვანი ნადგაბის (ნადების) სანწმენდი სითხეების დასამზადებლად. მათში მაღალია ჰიდროქსიდ-იონების კონცენტრაცია, ამიტომ მათი გამოყენების დროს საჭიროა სიფრთხილე.

პერიოდული კანონზომიერებები

როგორ იცვლება მჟავური და ფუძური თვისებები?

მჟავა მით უფრო ძლიერია, რაც უფრო ადვილად გასცემს წყალბადის კატიონს ელექტროლიტური დისოციაციის დროს.

1

არამეტალების წყალბადნაერთები

პერიოდში მარცხნიდან მარჯვნივ იზრდება მჟავური თვისებები. ჰალოგენწყალბადების შემთხვევაში მჟავური სიძლიერე ზემოდან ქვემოთ იზრდება რადიუსის ზრდასთან ერთად.

მესამე პერიოდი: SiH₄ < PH₃ < H₂S < HCl
ჰალოგენწყალბადები: HF < HCl < HBr < HI
2

ჟანგბადშემცველი მჟავები (HₙXOₘ)

ცენტრალურ ატომთან დაკავშირებული თავისუფალი ჟანგბადის ატომების რიცხვი (m - n) განსაზღვრავს მჟავის სიძლიერეს:

m - n = 0: სუსტია (HClO, H₃BO₃)
m - n = 1: საშუალოა (HNO₂, H₂SO₃)
m - n = 2: ძლიერია (HNO₃, H₂SO₄)
m - n = 3: ძალიან ძლიერია (HClO₄, HMnO₄)

ინტერაქტიული შედარების ტესტერი

აირჩიეთ წყვილი და შეამოწმეთ კანონზომიერება:

აირჩიეთ წყვილი ზემოთ მოცემული ღილაკებიდან...
ვირტუალური ლაბორატორია

დისოციაციის ვიზუალური ანიმაცია (ნახ. 1.25 & 1.26)

შეადარეთ ძლიერი და სუსტი მჟავების იონებად დაშლა და ბალანსი.

HCl → H⁺ + Cl⁻

მარილმჟავა (HCl)

ძლიერი მჟავა. წყალში სრულად იშლება წყალბადის კატიონებად და ქლორიდის ანიონებად.

დისოციაციის ხარისხი: ~100% (სრული)

ლაბორატორიული ანალიზი

პროცესის ისარი მხოლოდ ერთი ისარი (→)
ელექტროლიტის ტიპი ძლიერი ელექტროლიტი
ხსნარის არე მაღალი კონდუქტომეტრია
რჩევა: სუსტ მჟავებში წონასწორობა გადახრილია არადისოცირებული მოლეკულების მხარეს.
სახელმძღვანელოს სავარჯიშოები

კითხვები და დავალებები

თავი 1.10

1. დააკვირდით 1.25 ნახაზს. რატომ არის აუცილებელი შედარებისათვის ერთი და იმავე კონცენტრაციის ხსნარების გამოყენება?

პასუხი: იმისათვის, რომ ნივთიერებების სიძლიერე (დისოციაციის ხარისხი) სწორად შევადაროთ, საწყისი მოლური კონცენტრაცია აუცილებლად თანაბარი უნდა იყოს, ვინაიდან დისოციაციის მუდმივა და იონების რაოდენობა პირდაპირ არის დამოკიდებული ხსნარის კონცენტრაციაზე.

2. შეადარეთ ერთმანეთს დისოციაციის ხარისხი და მუდმივა.

პასუხი: დისოციაციის ხარისხი დამოკიდებულია ხსნარის კონცენტრაციაზე (განზავებისას ის იზრდება), ხოლო დისოციაციის მუდმივა (Ka) კონცენტრაციაზე არ არის დამოკიდებული — ის მუდმივი величинаა მოცემული ტემპერატურისათვის და ახასიათებს სუსტ ელექტროლიტებს.

3. მოცემულია ქლორის მჟავები: a) HClO, b) HClO₂, c) HClO₃, d) HClO₄. დაასახელეთ ყველაზე ძლიერი და სუსტი.

პასუხი: ყველაზე ძლიერია პერქლორმჟავა HClO₄ (სადაც m - n = 3), ხოლო ყველაზე სუსტია ჰიპოქლორმჟავა HClO (სადაც m - n = 0). თავისუფალი ჟანგბადის ატომების მეტი რიცხვი ზრდის O-H ბმის პოლარიზაციას.

4. შეადარეთ მჟავათა სიძლიერე: ა) გოგირდწყალბადმჟავა და სელენწყალბადმჟავა; ბ) სელენწყალბადმჟავა და ბრომწყალბადმჟავა.

პასუხი: ა) სელენწყალბადმჟავა (H₂Se) უფრო ძლიერია, ვიდრე გოგირდწყალბადმჟავა (H₂S), რადგან სელენის ატომის რადიუსი უფრო დიდია და წყალბადის მოწყვეტა უფრო ადვილია. ბ) ანალოგიურად, ჯგუფში ქვემოთ სელენწყალბადმჟავაზე ძლიერია ბრომწყალბადმჟავა (HBr).

5. შეადარეთ ჰიდროქსიდების სიძლიერე: ა) ნატრიუმის და მაგნიუმის ჰიდროქსიდი; ბ) ლითიუმის და კალიუმის ჰიდროქსიდი.

პასუხი: ა) NaOH უფრო ძლიერი ტუტეა, ვიდრე Mg(OH)₂, ვინაიდან ნატრიუმის კატიონს ნაკლები მუხტი და მეტი რადიუსი აქვს. ბ) კალიუმის ჰიდროქსიდი (KOH) უფრო ძლიერია, ვიდრე ლითიუმის ჰიდროქსიდი (LiOH), რადგან ჯგუფში ზემოდან ქვემოთ ტუტეების სიძლიერე იზრდება.

6. გააანალიზეთ ნახ. 1.26 და შეადგინეთ სუსტი და ძლიერი მჟავების დისოციაციის ტოლობები.

პასუხი: ძლიერი მჟავა (მაგ. HCl): HCl + H₂O → H₃O⁺ + Cl⁻ (სრული დისოციაცია, ~100%). სუსტი მჟავა (მაგ. CH₃COOH): CH₃COOH + H₂O ⇌ H₃O⁺ + CH₃COO⁻ (შექცევადი პროცესი, მცირე % დისოცირებული).
